# hurarusight

ふらる（hurarunium）の個人サイト。Astro 製。

## 開発

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # dist/ に静的ファイルを出力
```

## 記事の追加

`src/content/notes/` に `.md` を1つ追加する（frontmatter は `title` と `date`）。

## 旧版

3D名刺・粒子演出などを含む旧版は `archive/garden-v1` ブランチ / `archive-2026-10-05` タグに退避してある。
